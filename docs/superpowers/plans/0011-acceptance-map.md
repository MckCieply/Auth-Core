# Spec 0011 — acceptance map

Maps each acceptance criterion of [spec 0011](../specs/0011-google-and-microsoft-sign-in.md) to the tests and the e2e steps that guard it, for verifier
layer 2 ([`docs/workflow.md`](../../workflow.md#verification)). The tests are those of [plan 0011](0011-google-and-microsoft-sign-in.md); the task that builds
each is named in brackets. The .NET tests are in `tests/Auth.IntegrationTests/` (xUnit v3, PostgreSQL by Testcontainers: Docker must be running), with the fake
provider of `tests/Auth.FakeOidc` in process behind OpenIddict's HTTP client; the Angular sample's unit tests in `samples/notes-web/src/` (`npm test`) and its
Playwright tests in `samples/notes-web/e2e/11-providers.spec.ts` (Chromium and WebKit, run by `scripts/e2e-web.sh`). The live API checks are
`scripts/e2e-providers.sh` (the web stack with `tests/Auth.FakeOidc/compose.yml`; its header gives the commands), whose steps are named below.

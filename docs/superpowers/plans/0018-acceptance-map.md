# Acceptance map - plan 0018

of [the plan](0018-project-site.md) that writes them. The Node tests are in site/scripts/prebuild.test.mjs (run by `npm run build`
through the `prebuild` script); the Python cases are the `--self-test` cases of `scripts/release-notes.py` and `scripts/check-pins.py`.

test fail and restores it.

# Spec 0010 — acceptance map

Maps each acceptance criterion of [spec 0010](../specs/0010-private-accounts.md) to the tests and the e2e steps that guard it, for verifier layer 2
([`docs/workflow.md`](../../workflow.md#verification)). The tests are those of [plan 0010](0010-private-accounts.md); the task that builds each is named there. The .NET
tests are in `tests/Auth.IntegrationTests/` (xUnit v3, PostgreSQL by Testcontainers: Docker must be running; `dotnet test tests/Auth.IntegrationTests`); the Python
tests in `clients/python/tests/` and `samples/notes-api/tests/` (`pytest`); the Angular sample's unit tests in `samples/notes-web/src/` (`npm test`) and its Playwright tests
in `samples/notes-web/e2e/10-private.spec.ts` (Chromium and WebKit, run by `scripts/e2e-web.sh`). The live API checks are `scripts/e2e-private.sh` (the development stack; run
it after `scripts/e2e-signup.sh`), whose steps are named below.

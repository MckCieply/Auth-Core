# Spec 0012 — acceptance map

Maps each acceptance criterion of [spec 0012](../specs/0012-github-and-managing-logins.md) (with its Amendment of 2026-05-04) to the tests and the e2e steps
that guard it, for verifier layer 2 ([`docs/workflow.md`](../../workflow.md#verification)). The tests are those of
[plan 0012](0012-github-and-managing-logins.md); the task that builds each is named in brackets. The .NET tests are in `tests/Auth.IntegrationTests/` (xUnit
v3, PostgreSQL by Testcontainers: Docker must be running), with the fake provider of `tests/Auth.FakeOidc` in process behind OpenIddict's HTTP client and
the GitHub reader's own; the Angular sample's unit tests in `samples/notes-web/src/` (`npm test`) and its Playwright tests in
`samples/notes-web/e2e/14-settings.spec.ts` (Chromium and WebKit, run by `scripts/e2e-web.sh`); notes-api's in `samples/notes-api/tests/` (`pytest`). The live
API checks are `scripts/e2e-settings.sh` and `scripts/e2e-providers.sh` (the web stack with `tests/Auth.FakeOidc/compose.yml`; their headers give the
commands), whose steps are named below.
